# TRACE-X Synthetic Demo Dataset

ALL DATA IN THIS PACKAGE IS FICTIONAL AND SYNTHETIC.
It is intended only for a Smart India Hackathon demonstration.

## Recommended recording flow
1. CASE-001 — Operation Shadow Net
2. Evidence — upload/show `shadow_net_report.txt`
3. Entity Explorer — show Arjun Mehta, phone, device, account
4. Entity Resolution — show a candidate and confirmation/review
5. Graph Explorer — show the relationships
6. Cross-Case Correlation — show CORR-001/CORR-002
7. Temporal/Network Analysis
8. Patterns — show PAT-001/PAT-002
9. Contradictions — show CON-001
10. Intelligence — show FND-001/FND-002
11. Alerts — show ALT-001/ALT-002
12. Return to Dashboard

## Important demo language
A correlation is an analytical signal, not proof of guilt.
An entity-resolution result is a candidate until investigator confirmation.
Do not present the fictional names as real criminal subjects.

## Import note
The CSVs are generic demo fixtures. Depending on the exact current TRACE-X Prisma/API schema, field mapping or an import script may be needed.
